# Keybinds do rice

> Código-fonte dos atalhos fixos. Veja [keybinds.md](keybinds.md) para uso e edição.

| Atalho | Ação |
|---|---|
| `SUPER + setas` | Mover foco entre janelas |
| `SUPER + 1 … 0` | Ir para o workspace |
| `SUPER + SHIFT + 1 … 0` | Mover janela para o workspace |
| `SUPER + scroll` | Trocar de workspace |
| `SUPER + mouse (esq./dir.)` | Mover / redimensionar janela |
| `volume/brilho` | Ajustar volume e brilho |
| `mídia` | Play, pausa, próxima, anterior |

## Como editar

Certifique-se de que `rice/.config/hypr/binds.tsv` existe (gera com `menu.sh --init`).
